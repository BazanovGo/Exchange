# Exchange — исследование торговых стратегий на фьючерсах Московской биржи

**Все исследования в этом репозитории выполнены на котировках Московской биржи, полученных через сервис
MOEX AlgoPack:** фьючерсы на природный газ (NG) и нефть Brent (BR),
минутные, пятиминутные и часовые свечи за всю доступную историю.

Основа репозитория — **Exchange Research OS** ([`exchange/`](exchange/README.md)): фреймворк, который
проверяет торговые гипотезы на опровержение. Его задача — не найти стратегию с красивым бэктестом, а не дать
принять за закономерность случайность, переобучение или ошибку данных.

## Данные: MOEX AlgoPack

| | |
|---|---|
| Источник | MOEX AlgoPack (`apim.moex.com`) — рыночные данные Московской биржи |
| Инструменты | фьючерсы NG (природный газ) и BR (нефть Brent), FORTS |
| Свечи | 1, 5 и 60 минут; время московское, как отдаёт биржа |
| История | NG — с 2020-02-03, BR — с 2011-12-19, обе по 2026-10-03 |
| Склейка | вендор склеивает контракты по ближайшей экспирации без корректировки; контракт каждого бара — в поле `secid` |
| Где лежат | [`data/raw/moex_algopack/`](data/raw/moex_algopack/README.md) — CSV по годам и `manifest.json` |

Файлы получены из AlgoPack загрузчиком из отдельного репозитория (`trader`, `market_data/sources/moex_algopack/loader.py`).
Здесь они только читаются: модуль [`exchange.data.moex`](exchange/src/exchange/data/moex.py)
(`load_moex_algopack`, `moex_continuous`, `moex_dataset`) восстанавливает роллы по `secid` и строит
непрерывный ряд: скорректированный по отношению цен — для сигналов, торгуемый — для денежного результата.
Ни сети, ни ключей API для этого не нужно; исследования находят данные по переменной окружения
`EXCHANGE_MOEX_DATA`.

## Где используется синтетика

Синтетические ряды с заранее известным ответом нужны только для **самопроверки фреймворка**. Случайное
блуждание не должно получить вердикт выше `WEAK`, построенный эффект должен быть найден, подброшенное
подглядывание в будущее должно быть поймано. На этом строятся контроли и тесты (`exchange controls`,
`exchange/tests/`). Ни одно исследование на синтетических данных не основано.

Кроме файлов AlgoPack, пакет умеет читать собственные CSV и Parquet и загружать Yahoo Finance. Yahoo
оставлен для проверок на акциях и индексах: для фьючерсов он не подходит, так как не хранит контракты и
роллы.

## Быстрый старт

```bash
cd exchange
uv sync --all-extras
uv run pytest tests -q                               # 521 тест
uv run exchange controls --quick                     # калибровка фреймворка на синтетических контролях
export EXCHANGE_MOEX_DATA=$PWD/../data/raw/moex_algopack
# дальше — команды из research/seven_families/README.md и research/ma_crossover_5m/README.md
python tools/run_checks.py --title "что сделано"     # проверки перед публикацией
```

## Исходный прототип в корне репозитория

Каталоги `src/`, `notebooks/`, `orchestrator/`, `prompts/`, `research/`, `results/`, `scripts/` и `tests/`
в корне — исходный шаблон на vectorbt, с которого начался проект. Его ноутбуки работали на Yahoo Finance и
синтетическом `data/raw/SAMPLE.csv`. Аудит ([`exchange/docs/ARCHITECTURE_AUDIT.md`](exchange/docs/ARCHITECTURE_AUDIT.md))
нашёл в нём несколько проблем:
* период вне выборки участвовал в отборе параметров;
* не было поправок на размер перебора;
* сделки исполнялись по цене той же свечи, что дала сигнал;
* автономный агент запускался с `--dangerously-skip-permissions`.

Поэтому результаты прототипа не используются, код оставлен для истории и не развивается, оркестратор
запускать не следует. Прежнее описание прототипа — [`docs/LEGACY_TEMPLATE_README.md`](docs/LEGACY_TEMPLATE_README.md).

## Дисклеймер

Результаты — исторические бэктесты на реальных котировках Московской биржи, а не торговые рекомендации. Ни
одна из проверенных стратегий не доказала торгового преимущества после издержек. Прошлые результаты не
гарантируют будущих.
