# Журналы прогонов исследования

Сценарии, которыми исследование запускалось в рабочем окружении 2026-10-14 — 2026-10-15,
и их журналы — как свидетельство того, что и в каком порядке считалось. Пути в сценариях
(`/home/user/...`) относятся к тому окружению; воспроизводить исследование нужно по командам
из [`../README.md`](../README.md), а не этими файлами.

| Файл | Что делал |

| `post1.sh` → `post1.log` | анализ этапа 1: издержки, сверка раскладки сетки BR, кросс-рынок |
| `ng3.sh` → `ng3.log` | анализ этапа 3 для NG |
| `post3.sh` | анализ этапа 3, финалисты, тест траекторий на 200 путях (журнал пуст: цепочка была прервана перезапуском контейнера и доделана `resume.sh`) |
| `resume.sh` → `resume.log` | возобновляемая цепочка: каждый шаг пропускается, если его результат уже есть |
| `replateau.sh` → `replateau.log`, `re_s*_*.log` | пересчёт всего, что зависит от сглаживания по плато, после исправления краёв |
