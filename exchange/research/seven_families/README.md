# Семь семейств трендовых и кэрри-стратегий на NG и BR

Исследовательский прогон: семь классических семейств, два инструмента MOEX
(`NG` — природный газ, `BR` — Brent), часовые данные, сведённые в дневные бары.
Всё исполнение идёт через движок пакета (`exchange.backtest.engine`), то есть
next-bar по построению; сигналы считаются на ratio-adjusted непрерывной серии,
а отчёт о доходности — на торгуемой.

## Порядок запуска

```bash
export EXCHANGE_MOEX_DATA=/path/to/moex          # каталог 60-минутных файлов
python run_all.py      # бэктест + оптимизация 125 конфигураций  -> results.pkl
python run_stats.py    # дефляция, PBO, CPCV, walk-forward        -> stats.pkl
python run_final.py    # леджер p-value поиска                    -> search.pkl
python add_hac.py      # HAC-p (без порога разрешения бутстрэпа)  -> search.pkl
python run_final.py    # мультитест, RC/SPA, серии, вердикты      -> final.pkl
python make_report.py  # рендер отчёта из пиклов                  -> REPORT.md
python sweep.py        # весь перебор: IS и OOS каждой из 125 конфигураций -> results/
```

Скрипты запускаются из этого каталога (они импортируют друг друга как
модули верхнего уровня). Все случайные числа засеяны константами в коде.

## Что здесь принципиально

* **Отбор параметров только на in-sample.** OOS-период оценивается ровно один
  раз, для победителя. Ни одно решение не принималось после просмотра OOS.
* **Один общий бюджет мультитеста.** Дефляция Шарпа заряжается не размером
  сетки семейства, а всеми 125 конфигурациями программы.
* **Издержки в базисных пунктах от ноционала**, а не в рублях за контракт:
  результат не зависит от множителя контракта и курса.
* **Полоса ребалансировки 20%** у vol-target сайзинга — зафиксирована заранее,
  не оптимизировалась.
* **Carry — прокси по коэффициентам ролла**, а не наблюдаемая срочная кривая:
  в данных нет одновременных котировок соседних контрактов.

## Известные ограничения

Две бумаги — это не кросс-секция. Семейство 4 (cross-sectional momentum)
вырождается в спред NG против BR, семейство 6 — в двуногий портфель. Их
результаты нельзя переносить на настоящую кросс-секцию из 20+ рынков.

## Ноутбук со сделками

`build_trades_notebook.py` собирает и исполняет
`../../notebooks/02_trades_seven_families.ipynb`: суть каждой системы и её сделки
на графиках. Исходники ячеек лежат в `notebook_cells/` отдельными файлами —
так они редактируются и проверяются синтаксически как обычный код, а не как
строки внутри JSON.

```bash
EXCHANGE_MOEX_DATA=/path/to/moex python build_trades_notebook.py
```

Графики строятся через те же `harness`/`families`/`run_all`, что и отчёт,
поэтому показывают ровно те сделки, которые в него попали.
