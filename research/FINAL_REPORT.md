# Итоговый отчёт автономного исследовательского цикла

**Период:** 2026-07-04 — 2026-07-05 · **Итераций:** 5 · **Гипотез: 19 прогонов
(16 уникальных идей + пере-аудиты и контроли)** · Полный каталог:
[`catalog.csv`](catalog.csv), журналы — `research/H*/report.md`, живая база
знаний — [`../knowledge_base.md`](../knowledge_base.md).

Каждая гипотеза прошла полный цикл: формализация → код → backtest →
оптимизация сетки (vectorbt) → плато устойчивости → OOS 70/30 →
walk-forward с пере-оптимизацией → Monte Carlo → вердикт переобучения →
журнал. Ни одна идея не была брошена без полного анализа; ни один вердикт
не выносился по доходности.

## 3. Рейтинг комбинаций индикаторов

1. **Одиночный осциллятор на структурных данных** (Williams %R, z-score,
   Bollinger) — единственные конструкции, прошедшие все гейты; %R
   (диапазонная нормировка) устойчивее дисперсионной.
2. **Тренд-фильтр + осциллятор-вход** (ema_rsi, этап 02) — лучший гибрид на
   дрейфовых данных.
3. **Согласованность старшего/младшего тренда** (htf_up + ema_slope_up,
   этап 04) — единственная комбинация-фильтр с реальным OOS-улучшением.
4. Антирейтинг: стеки из 3+ условий (H001/H002), «растущий индикатор»
   (ADX rising), volume-confirmation импульса (H004/H010), свечные паттерны
   (H007), режимные переключатели с лагающей классификацией (H008).

## 4. Рейтинг методов управления позицией (этапы 03 + H019)

1. **Take Profit** — реальное улучшение у 4/6 стратегий (Δ OOS Sharpe до +0.45);
2. **Частичная фиксация прибыли** — 4/6, стабильно снижает просадку;
3. **Trailing + partial** — 3/6;
4. **Выход по противоположному сигналу** — сильный baseline; в MR-классе
   вариация точки выхода (среднее vs дальний край, H019) сохраняет
   устойчивость — альфа во входе;
5. Антирейтинг: **Time Stop** и **Break Even** — систематические ложные
   улучшения; замена сигнальных выходов трейлингом — рост просадки.

Money management (этап 05): полный Kelly на десятках сделок не
идентифицирован (bootstrap-CI шире оценки); практическое правило —
`min(quarter Kelly, 25% капитала, 2% риска на сделку)`; Monte Carlo при
такой доле: P(разорения) ≈ 0, медианная просадка ~5%.

## 5. Валидация методологии (главный актив проекта)

* **Специфичность**: на бесструктурном GBM отбраковано 13/13 прогонов,
  включая negative leg лучшей конструкции (H017) — пайплайн не выдаёт
  ложных открытий.
* **Чувствительность**: на OU-структуре 5/5 MR-прогонов promising, с
  переносом на независимую реализацию процесса (H018).
* **Positive control окупился немедленно**: первый же контроль вскрыл
  inf-Sharpe баг walk-forward отбора (пустой портфель → бесконечный Sharpe
  → «победа» в idxmax), искажавший все ранние WF-вердикты. После фикса —
  пере-аудит затронутых гипотез (вердикты подтвердились).
* Momentum-чувствительность частичная: H014 (OOS 0.91, 75% окон) остановлен
  плато-гейтом — пороговые momentum-сетки образуют узкие плато; это
  документированное ограничение методики, не дефект класса.

## 6. Где вероятность обнаружения альфы наиболее высока

Центральный вывод цикла: **альфа живёт в данных, а не в индикаторе.**
Когда в серии есть mean-reversion структура, её снимает любая разумная
MR-конструкция; когда структуры нет — не помогает ни одна комбинация из
25+ индикаторов. Следствия:

1. **Искать следует инструменты/таймфреймы с измеримой структурой**
   (значимая автокорреляция приростов, режимная персистентность), а не
   новые комбинации индикаторов поверх произвольного инструмента.
   Скринер структуры — более ценный инструмент, чем новый осциллятор.
2. Наиболее вероятные носители MR-структуры в реальности: спреды и пары,
   интрадей после шоков, стационарные относительные величины (basis,
   funding), диапазонные валютные пары.
3. Momentum-структура требует соответствия таймфрейма стратегии длине
   режимов (урок H013/H014) — на дневках это многомесячные фазы.
4. Комбинаторный перебор индикаторов имеет быстро убывающую отдачу:
   последние итерации давали только подтверждения известного — критерий
   остановки «новые комбинации сводятся к известным» выполнен.

## 7. Рекомендации для следующего этапа

1. **Реальные данные**: подключить Yahoo/MOEX/Polygon (лоадер — один класс)
   и прогнать скринер структуры по вселенной инструментов; MR-тройку
   тестировать только там, где структура измерена.
2. **Скринер структуры как продукт**: автокорреляция, variance ratio,
   Hurst — до каких таймфреймов и инструментов дотягивается MR/momentum.
3. **Портфель**: promising-конструкции на некоррелированных носителях
   структуры + money-management правило этапа 05.
4. **Методика**: калибровка плато-гейта для пороговых momentum-сеток;
   Deflated Sharpe / White's Reality Check как формальная поправка на
   множественность (19 прогонов уже требуют её для честных p-value).
5. **Исполнение**: интрадей-данные, задержки, стаканные издержки — вся
   инфраструктура (exit-симулятор, from_orders) к этому готова.
